# Continuous sliding control in the A/B study

2026-11-05, Stage 2/3 engineering revision `sliding-five-close-v1`.

## Decision contract

New A/B allocations and the four A/B engineering examples select the revision explicitly. Historical allocations without it retain the previous behavior. Each five-trial checkpoint starts when the last response closes at four seconds. A separate immutable response snapshot supplies that answer for the latest twenty behavioral trials. It is not inserted into the completed trial store. For example, request 25 uses behavior 6–25 and the latest **complete** five-trial physiology window 20–24. It does not claim to have physiology through trial 25. Both sets of indices are one-based here; stored phase-trial identifiers are zero-based.

Physiology is re-evaluated every completed trial over 22.5 seconds. A routine level change retains the predictions and no longer imposes a post-change dwell counter or a three-prediction minimum. Records include all five levels, transition trial IDs, within-window level-change times, clipped actual playback intervals, union exposure duration and movie fraction. The last level is not a substitute for actual playback. Hard interruptions, mount loss, stage changes and playback faults retain isolation/invalidation. Quality, clock uncertainty, completeness, phase continuity, model eligibility, fallback labeling and the existing actual L1 exposure and safe-media-boundary checks remain. The exact latest complete window must be valid, time-aligned, revision-compatible and covered by calibration. Old or missing predictions cannot be silently substituted.

Guard receives the exact prediction used and a separate ID for the just-closed behavioral response. Observe/enforce are unchanged. Guard can still dispute cross-condition applicability, insufficient gaze or invalid evidence; retaining history in the controller does not grant authorization. In particular the Guard's existing current-condition checks on an ON proposal's evidence remain conservative. It does not establish causal physiological attribution.

## Calibration/model compatibility

The previous training extractor excluded transitions and cross-block windows. New sliding sessions re-extract and label continuous five-trial windows in calibration, including mixed-level windows, and train a fresh model with the same four features and within-window RT/correctness label formula. The model report records the new window revision and eligible labeled level patterns. At prediction time unseen patterns and an absent/wrong revision cannot support an action. The runtime still requires all original personal-model admission gates. No saved Gin model was converted, refitted or admitted.

For held-out validation, purge training windows sharing **any source block** with the held-out windows; permutation refits also purge overlapping sources of the shifted labels. Mixed-window held-out predictions must cover both classes and reach the configured AUC floor in addition to the original gates. A failed or unavailable check is a failure, not permission to weaken admission. This may reduce model yield with four calibration blocks. Pilot signal qualification, coverage and statistical assumptions are outstanding.

## Presentation and deadline

At response close Unity asynchronously posts the request. It does not wait or move the next onset. A matching, fresh response received **before** the scheduled 4.5-second boundary can take effect immediately before the next stimulus. A response received at/after the deadline, for a different active trial, revision, epoch or evaluation, is rejected. A timely approved action can still be deferred by the active-media gate; stale pending actions are not reused. The last request at 95 can now affect trial 96. Unity logs the deadline, roundtrip and acceptance; use actual execution receipts to count delivered switches. New Python and Unity sources must both be in use.
