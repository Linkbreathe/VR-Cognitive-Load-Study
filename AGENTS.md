# Project conventions

- Use English for all project UI, instructions, documentation, authored filenames, code comments and new content. Do not introduce Chinese localization.
- After every major update, update `Docs/ProjectLog.md` in the same work: record the date, version or revision, project stage, reason, concrete changes, validation evidence, pending checks and links to detailed review documents. Keep its current-status summary accurate, retain historical entries, and update `Docs/AcceptanceRecord.md` and `Docs/ExperimentGuide.md` when acceptance status or operation changes. Major updates include changes to task rules, timing, presentation, media, interaction, data/logging, architecture or build/device support. Distinguish implemented, software-verified and physically verified behavior; do not mark unperformed checks as passed. All records must be in English.
- This is a controlled VR cognitive task, not an entertainment game. Do not add music, animated scenery, changing exposure, or formal-trial correctness feedback.
- Keep Easy and Hard presentation identical except for their task rules. Preserve stimulus timing, geometry, response scoring, reproducibility and event logging unless explicitly asked to change them.
- Record visual revisions in the session metadata. Never mix editor or synthetic tests with participant data.
- The available test headset is Quest 3. Quest Pro remains a supported target, not a verified device.
