# Stage 1 实施与验收记录

日期：2026-11-01。当前状态：场景与实验流程已实现，自动化检查和编辑器集成检查通过；Quest 实机验收未完成。不得把当前交付标为“已通过全部 Stage 1 验收”。

## 已实现

- 新建独立 `NBackExperiment` 场景；原始 SampleScene 保留。
- 灰色封闭房间，柔和固定光照，无音效、装饰动画和后处理。固定世界坐标任务区、坐姿校准、约 6° 圆球。
- 0-back / 2-back、各自预热、练习与正式数据分离、可配置正式顺序、25 秒休息、规则确认。
- 固定 3 秒周期、1 秒显示、2.5 秒回答截止、单次响应、重复/同时/边界输入拒绝。
- 可重现随机序列，每正式区块 10 匹配 + 20 不匹配；不可在正式区块中改变配置/规则。
- 暂停、恢复、重开新会话、失焦/后台保护、停顿标记、逐题持久化。
- 配置快照、事件时间与帧号、CSV/JSONL、独立指标重算脚本。
- Android ARM64 / IL2CPP / OpenXR、Meta Quest 支持与 Touch Pro 动作资源配置。
